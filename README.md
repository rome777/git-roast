# 🔥 GitRoast (깃로스트)

[![GitRoast 서비스 바로가기](https://img.shields.io/badge/🔥_GitRoast-서비스_바로가기-F97316?style=for-the-badge)](https://git-roast-three.vercel.app)

겉으로만 그럴싸하게 채워둔 기록인지, 정말 알차게 채운 기록인지 솔직하게 털어놓기 어렵다면 깃로스트에 주소를 넣어보세요. 쌓아둔 활동 기록을 바탕으로 뼈 때리는 팩트 폭격과 현실적인 피드백을 전해주는 서비스입니다.

---

## 어떤 서비스인가요?

혼자서 무언가를 기록하다 보면 스스로에게 관대해지거나, 내가 정말 잘하고 있는지 착각하기 쉽습니다. 주변 사람들에게 물어봐도 듣기 좋은 칭찬만 돌아오기 마련입니다.

깃로스트는 눈치 보지 않고 공개된 기록을 그대로 읽어내어 가장 아픈 곳을 솔직하게 짚어줍니다.

* **현실 팩폭 (매운맛)**: 작심삼일의 흔적, 겉핥기식 기록, 방치된 흔적을 눈치 보지 않고 가감 없이 털어냅니다.
* **성장 조언 (순한맛)**: 뼈 맞고 쓰린 마음을 달래며, 앞으로 어떻게 채워가면 좋을지 차근차근 방향을 짚어줍니다.

결과는 한눈에 들어오는 요약 카드로 정리되며, 나를 돌아보는 자극제로 저장해 둘 수 있습니다.

---

## 이용 방법

1. 점검받고 싶은 공개 기록 주소를 넣습니다.
2. 매운맛(현실 팩폭) 또는 순한맛(조언)을 선택합니다.
3. 잠시 후 솔직하게 털어놓는 피드백 카드를 확인합니다.

*누구에게나 열려 있는 공개 기록만 확인하므로 별도의 절차 없이 바로 이용할 수 있습니다.*
