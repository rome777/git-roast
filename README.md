# 🔥 GitRoast (깃로스트)

<a href="https://git-roast-three.vercel.app">
  <img src="docs/button.svg" alt="GitRoast 바로가기" />
</a>

<br/>

겉만 그럴싸한 **깃허브(GitHub) 잔디밭**인지, 속까지 알찬지 짚어드립니다.  
**GitHub 아이디나 리포지토리 주소**를 넣으면 눈치 보지 않고 뼈 때리는 현실 피드백을 남겨주는 서비스입니다.

</div>

---

### 🔥 주요 기능
* **현실 팩폭 (매운맛)**: 작심삼일의 흔적과 겉핥기식 기록을 가감 없이 털어냅니다.
* **성장 조언 (순한맛)**: 아쉬운 점을 짚고 앞으로 채워갈 방향을 차근차근 제안합니다.

### 💡 이용 방법
1. 점검하고 싶은 **GitHub 아이디 또는 리포지토리 주소** 입력
2. 매운맛(팩폭) 또는 순한맛(조언) 선택
3. 솔직한 요약 분석 카드 확인
